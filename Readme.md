# Сайт препарата «Бифитта®»
Многостраничный коммерческий адаптивный веб-сайт (4 стр) препарата Бифитта®. Проект реализован на чистом HTML5/SASS и JavaScript с семантической версткой.

## 🛠 Технологический стек

### Frontend
- **HTML5** — семантическая верстка, БЭМ-методология
- **SASS/SCSS** — модульная структура, сброс стилей, переменные, медиа-запросы
- **JavaScript** — работа с DOM, обработка событий
- **API Ютека** — карта аптек с геолокацией

### Библиотеки и плагины
- **Swiper** — слайдер
- **GSAP** - анимации
- **MenuSpy** - синхронизация меню со скроллом

## 🎯 Ключевые функции

### UI/UX элементы
- Липкая навигация для шапки при скролле
- Плавная навигация по странице
- Адаптивное бургер-меню для мобильных устройств
- Анимации:
	- «Активный состав» - 3D-переключение картинок при скролле
	- «Симптомы» - раздвижение облаков + появление препарата
	- «Препарат способствует» — последовательное появление 5 пунктов меню
- Адаптивные карусели статей
- Аккордеоны для полезной информации
- Кнопка Показать еще
- Интерактивные карты
- Медицинские предупреждения и дисклеймеры


## 🔧 Технические особенности

### Адаптивность
- Адаптивный дизайн
- Медиа-запросы
- Кросс-браузерная совместимость


**Проект демонстрирует навыки разработки коммерческих многостраничных веб-сайтов на чистом HTML5/SASS и JavaScript с адаптивным дизайном, интерактивными элементами в медицинской сфере с соблюдением всех нормативных требований.**
